# 弹道与子弹物理系统

## 项目描述

弹道与子弹物理系统的bug修复项目。核心模块 `ballistics/bullet_physics.py` 存在多个已知bug，需要修复后使测试全部通过。

## 已知问题

- 弹道计算只用直线方程不考虑重力飞行时间
- 子弹下坠完全没做所有距离都不会下坠
- 风速影响完全没做顺风逆风都一样
- 穿透只检查能否穿透不计算伤害衰减
- 子弹生命周期写死不过期消失无对象池

## 运行测试

```bash
python -m pytest tests/test_bullet_physics.py -q
```

修复目标：所有 15 个测试全部通过。

## 技术要求

- 纯Python标准库，不引入第三方依赖
- 不修改测试文件
- 保持现有API接口不变
